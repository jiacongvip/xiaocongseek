## 启动 / 重启

改插件或面板后必须重启 3080。**不要** `pkill -f "dsh --profile web"`（太宽，会误伤）。只杀本端口监听进程：

```bash
export PATH="$HOME/.local/bin:$HOME/.local/node/v24.22.1/bin:$PATH"
# 只停 3080
kill "$(lsof -nP -iTCP:3080 -sTCP:LISTEN -t)" 2>/dev/null || true
cd "/Users/jiacong/Desktop/开发文件/小葱/dsh-newapi-fork/deepseek-harness"
pnpm dsh --profile web --no-open --port 3080
```

也可用 `dsh-newapi-fork/scripts/start-web.sh`（脚本里的 pkill 带了 `--no-open --port`，相对安全）。日志：`/tmp/xiaocongseek-web-local.log`。

验证：

```bash
curl -s http://127.0.0.1:3080/digital-human-studio/ping
# version 应为 0.9.6，tools 含 dh_list_materials
```

## 产品现状（截至 0.9.6）

工作台左侧：**主页** → **公司**。公司卡片按钮：**档案 / 素材 / 数字人 / 音频 / 图片 / 成片**。

### 公司空间

- 一家公司 = 一个 `StudioSpace`。登录账号可以很多家，磁盘按空间分开。
- 档案字段：对外身份、主营/卖点、对谁说、口吻、不要说、范例口播。存在空间上，不是聊天记忆。
- 空档案第一轮：对话里主动收档案，`dh_update_brief` 写入；不要让用户自己去左侧填，除非他们说要自己填。
- 对话公司选择器按 **会话锁定**。宿主 `sessionSpaces` + 客户端 `xdh.digital-human.space.sessions`。没选公司的对话锁在 `default`。聊天工具走 `spaceForAgent`，不要串到另一家。

### 成片记录（0.9.5）

- 面板任务和对话 `/dh`、`speakTalkingHead`、生图都会 upsert `history.json`（每家最多 40 条）。
- 面板打开时 merge 宿主 + 本地。对话里出片也要进这家公司的「记录 / 成片」。

### 素材柜（0.9.6）

- 槽位：`product` 产品、`store` 门店、`logo` Logo。单文件上限 200MB，每家最多 80 件。
- 工作台可看、可拖、可传、可删；Finder 直接丢进对应文件夹也会被扫进 `catalog.json`。
- HTTP：`GET/POST /digital-human-studio/materials`，`GET/POST /digital-human-studio/materials/file`。
- 工具：`dh_list_materials`（可按 slot 过滤），返回本地绝对路径给 `dh_add_video`。
- **还不是剪映轨道替换。** VectCut 目前只有追加：`dh_create_draft` → `dh_add_video` → `dh_save_draft`。用户说「换件」时，先从柜子取路径再 add；技能 `加片.md` 写明了工具没有 replace。

### 数字人 / 生图 / 预览

- 数字人任务走 XiaocongAPI `POST /v1/tasks/xiaocong-digital-human`，再 `GET /v1/tasks/{id}` 轮询。侧栏面板在 `ui-settings-account`，不是旧的 VectCut 设置页。
- 对话 `/dh` → `speakTalkingHead`；相关工具 `dh_avatar_*`。
- 生图走 XiaocongAPI `/v1/images/generations`（grok2api + 多米 gpt-image-2 家族，插件 `xiaocong-digital-human` 渠道）。多米余额不足时会卡住。
- IDE / 工作台打开本机 mp4、常见音频：`ui-sidebar-documentpreview` 的 media renderer，src 走 `/api/file?path=`。大约 50MB 上限，无 Range；超大视频仍可能预览失败。

### 混剪

- 本机 VectCut。技能在 `digital-human-studio/skills/vectcut-local/`（用户目录也会发现 `~/.dsh/skills/vectcut-local/`）。
- `dh_add_audio` / `dh_add_image` 还没接上工作台换件流。

# 小葱统一发布：原GEO薄适配（当前默认实现）

## 已纠正的接入方式
不需要用户再建授权后端，不需要新造 reserve/claim/settle 服务，也不强制 WebAuthn/安全键登记。旧第二阶段要求已废弃。

当前默认执行路径：公司发布包 → 已人工检查快照 → 明确公司账号绑定 → 任务 → 宿主认证/同源JSON人工确认 → 一次性会话+CSRF+nonce → 原GEO正式 `/postVideo` → 本地任务结果。

原 `client_auth` / `client_permissions` / 原累计次数账本仍是最终权威；**不是**把迁入的 `post_file` 脱离原权限环境直接执行，也不把历史计数从零重建。

## 使用顺序（构建完成，尚未重启加载）
1. 等小葱工作台重启加载后，从公司卡进入发布包，保存成片、封面和文案，人工检查。
2. 发布管理 → 连接原GEO：显示默认本机地址 5409，但不会自动连接/启动。请自行按原产品方式打开原GEO。仅允许loopback根地址，配置的真实授权/权限开关来自原服务，不是示例配置。小葱不启动原服务；原GEO正常启动时它自身原有定时机制仍按原设置运行，本轮未修改或验证。
3. 原服务若要求授权，用原用户名密码或原激活码按原客户端协议登录。产品标识仅在原授权产品需要时填写。令牌只在小葱后端内存，不回传Web/AI、不持久化、不复制原账号登录态；重启后需重新连接/授权。正常合法授权可能受原设备名额限制，不能绕过。
4. 点“从原GEO选择账号”，仅调用 `/getAccounts` 摘要，不调用会验证Cookie的 `/getValidAccounts`。明确选择一个账号绑定当前公司；不会默认导入或跨公司重复绑定。该摘要状态不是实时平台登录验证；平台账号登录/修复仍在原GEO完成。
5. 明确选择绑定，准备草稿；Web、插件与会话锁定公司的AI工具共用领域服务。AI可以查改包/排期、查任务、准备草稿，不能人工检查、绑定账号、连接授权、获取确认nonce、批准或执行。
6. 在任务完整预览核对公司、原账号ID/名称、平台、标题、正文、话题、视频/封面、内容版本。点“我已核对完整预览，确认立即发送”，再次确认后委托原GEO。日历时间仅记录，发送为立即执行，不启动调度器。
7. 原GEO继续执行原认证、权限与历史额度检查并写原任务记录。原返回 success/task_id 不作为平台最终发表证明。日历不会自动变为已发布。

## 保持原协议与账本
- 协议证据：原 `sau_backend/sau_backend.py` 的 `/getClientAuthServerConfig`、`/getClientPermissionContext`、`/getAccounts`、`/postVideo`；`utils/client_auth.py`、`utils/client_permissions.py`；`react_frontend/src/lib/clientAuthApi.ts`。
- 登录/激活/刷新沿用 `/login`、`/activate`、`/refresh`，aid/product_key/设备字段与原客户端对齐；服务端发送 Bearer + X-Client-Aid。新的安装ID仅是小葱自己的非秘密设备元数据，不复制原配置或数据库。
- 原配置启用认证时无授权就阻塞；显式 allow_publish=false 拒绝；权限缺省继续使用原 allow_when_missing 语义；limit<=0拒绝。正额度必须由原 `/postVideo` 的 `count_today_publish_attempts()` 检查原 `publish_task_records`，本地没有从零开始的累计计数。
- 原正式 `/postVideo` 是唯一发送通道；不调用私有未文档接口，不调用原无真实执行实现的 retry/cancel 路由，不自动重试，也不改原GEO配置。
- 登录使用原配置的主授权URL（缺省主URL时取备用URL），HTTP/HTTPS沿用原明确配置，并在UI展示授权中心，原配置为HTTP时警示未加密；不自动从HTTPS降级，不复制原忽略TLS证书的降级行为，不在显式拒绝后换中心重试。已过期令牌需要显式刷新/重新登录；没有后台心跳或自动刷新。

## 人工确认与安全边界
- 使用既有宿主认证、原same-origin检查、仅JSON POST；专用确认路由与普通管理/AI入口分离。
- nonce+CSRF随机值仅专用UI确认响应返回，绑定公司/任务/账号/内容摘要/授权连接版本/宿主会话，2分钟过期、一次消费。更换会话/账号映射/媒体/版本或重放都拒绝。
- 此边界防注册AI工具越权、跨公司、CSRF和重放；不宣称普通UI按钮可抵御已控制宿主的恶意管理员、任意同源脚本/XSS或本机进程。
- 从本公司受控资源解析路径；快照摘要复核后创建私有不可变媒体副本，再委托本机原GEO读取；请求不接受任意路径/远程媒体URL，不获取外链，无SSRF媒体下载。原账号文件引用仅在后端读取原API摘要并原样传回原API，不读Cookie内容，不给前端或AI。
- 本机端口与aid构成服务标识，localhost/127.0.0.1/::1别名归一；原API没有跨端口实例标识，不宣称识别多个代理端口指向同一原库的情况。本地wx持久任务标记+服务占用保证本接入自身串行和一次执行；原GEO的其他入口仍受其自身原有并发实现约束，不能声称改变了原账本的跨客户端原子性。
- 网络中断/进程中断/无最终证据均不盲目重试。可能仍执行的请求保留媒体副本与占用，避免先删媒体。用户可在原GEO/平台核对结束后，通过专用UI一次性确认仅解除占用；不重发、撤回、改成功或改日历。未知任务及同视频同账号仍阻止换版本盲发。

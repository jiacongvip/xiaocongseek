# 规则：混剪

适用：用户说「做个视频 / 混剪 / 拍条短视频」。客户不专业，目的还是要问，但用人话问；专业事先我们做。

**禁止对客户说的**

- 转化、CTA、分镜、入点出点、画幅、完播率、B-roll
- 让他们去左侧工作台填表、自己分类素材
- 整段素材往时间线一倒

## 开口（人话问目的，我们定做法）

1. 静默 `dh_get_brief`。用户给了本地文件夹时先 `dh_ingest_local_folder` 入库，再 `dh_list_materials`。pending 只看封面并 `dh_label_materials`。禁止直接对原目录 `dh_add_video`，禁止每次通读全部素材。
2. 用一句话问目的，给选项：「做出来，你更希望看的人怎样？想来店看看 / 私信问你 / 先记住你这家店。回一个就行，别的我来。」
3. 系统提示里已经带上本次 jiancai-viral 剪法正文。**禁止** read/cat/shell 去打开 `talk.md` 或其他 rules。按正文镜序和口播做。对外只用开头/中间/结尾三句人话讲方案。配音先问：「配音用哪个？热心老板 / 避坑提醒 / 稳重师傅 / 带看效果 / 用我的声音。」选好 `dh_set_voice` 再 `dh_add_narration`。用我的声音就让他们丢一段说话录音，`dh_clone_voice`。不要 say。垫乐自己找：先 `mcp__conte-de-fees__search_music`，确认 `licenseNote` 没有单独限制，再 `mcp__conte-de-fees__download_music` 存进 `~/.dsh/music`，然后 `dh_add_music` 传下载到的 path。没有合适的再 `dh_find_music`。对外只说垫了哪首。客户说先不要就跳过。自己的曲子丢进对话。不要用网易云、QQ 音乐、酷狗。
4. 没素材：只说「把店里或产品视频丢进对话就行」，然后停。禁止示例 URL。
5. 卖点不清楚时再问一句「店里主推啥」。不要问他们怎么剪。

## 下刀（对客户不可见）

内部按镜剪。不要把路径、秒数、路线名称甩给客户。

1. `dh_engine_status` → 需要则 `dh_engine_start`。
2. `dh_create_draft`（1080×1920）。
3. 每一镜单独 `dh_add_video`：`path` + `start` + `end`。不要一次 `paths` 整段倒进去。
4. 口播 `dh_add_narration`（两三句人话）。垫的产品/门店镜 `volume: 0`。
5. 花字先问：「画面上的大字要哪种？黄底大字 / 白字黑边 / 店招红金 / 橙色提醒 / 先不要。」选好后 `dh_add_local_styled_text`，`style` 就用这四个名字，字不超过 8 个。黄底大字、橙色提醒出前 3 秒；白字黑边贴底；店招红金写店名。不要让客户说编号，不要改用 `dh_add_text`。
6. `dh_save_draft`。
6. 告诉用户：去 **剪映** 打开刚做好的草稿看一眼，不行再说改哪。

## 专业默认（我们自己守）

- 成片 15–20 秒，单镜 1.5–3 秒，钩子不超过 3 秒
- 有产品素材至少 1 镜特写；有门店素材至少 1 镜环境
- 同一家店连续做，换路线，避免千篇一律
- 同一文件不要连用两镜，除非客户要
- 一段失败：对外说「有一段没用上」，问要不要跳过

## 配音 / 生图

口播先让客户选声音，再 `dh_add_narration`。要自己的声音用 `dh_clone_voice`。不要本机 `say`。垫乐先 `dh_find_music`，再用 `dh_add_music` 的默认音量。不要测分贝，不要改音乐文件，不要自己抬音量，不要去网上下载。已有 wav/mp3 再传给 `dh_add_music` 的 path。只调用已有的 `dh_*`，不要编造工具名。花字用 `dh_add_local_styled_text`，名字用黄底大字 / 白字黑边 / 店招红金 / 橙色提醒。

# 建材家装爆款（内部技能）

给**模型**用，不给客户点。客户不专业：用人话问目的，钩子、节奏、选片、入点由我们按本技能做。

下游剪辑走 `xiaocongcut-local` 的 `dh_*`。本技能只管**这条片子怎么拍才像爆款**。

## 每次必做

1. 静默 `dh_get_brief`。用户给了本地文件夹/「这里有几个视频」时，先 `dh_ingest_local_folder` 入库，再 `dh_list_materials`。pending 只看 `coverPath` 封面，用 `dh_label_materials` 写清是什么、干什么用。禁止直接读原目录全部成片，禁止每次把素材夹通看一遍。已 ready 的只用目录卡（path + useFor + 时长）。
2. **不问，直接做。** 客户没说方向，就按「有人看完会来问你价」剪（`rules/pitfall.md`；系统提示里有指定内部路线就用指定的）。建材家装这条路最稳，不需要他先做选择题。他要是自己说了「我想让人来店里」，再按他说的走。**禁止**开口就问"你是要私信还是到店""要引流还是成交"——他听不懂，答了也是猜。
3. 按定好的路线剪。系统提示里已经带上对应剪法正文，**禁止**再用 read/cat/shell 打开 `talk.md` 或其他 rules 文件。按正文里的镜序、时长、口播句式做。
4. 对外只用开头/中间/结尾三句人话讲方案，**和成片一起给**，不要先停下来等「行」再下刀。花字和音效照下面「花字和音效」小节配，交付时一句话说明「花字用的是手写笔刷+深色卡片，要换告诉我」。配音默认热心老板，`dh_set_voice` 后再 `dh_add_narration`；客户明确说了想用自己声音，就收一段录音 `dh_clone_voice`。不要本机 `say`。垫乐优先用 `dh_quick_edit` 的 `bgm: "auto"`，草稿模式走 `dh_find_music` + `dh_add_music`。不要测分贝、不要改音乐文件、不要去网上搜商用受限歌曲。
5. 缺该路线必需素材：改用系统提示里的下一条路线，不要硬剪，也不要让客户填表。只说「把店里或产品视频丢进对话就行」。

## 路线（客户说的方向 → 剪法）

| 客户这么说 | 实际是什么 | 优先路线 | 必读 |
| --- | --- | --- | --- |
| 想让人来店里看看 | 拉人到店 | 带进店 → 新旧对比 → 结果先行 | `rules/walk.md` / `rules/contrast.md` / `rules/result.md` |
| 想让人来问价 / 有没有货 | 来客户询价（行话叫"私信、留资"） | 避坑快切 → 干活现场 → 老板出镜 | `rules/pitfall.md` / `rules/hands.md` / `rules/talk.md` |
| 先让人记住这家店 | 品牌印象 | 老板出镜 → 带进店 | `rules/talk.md` / `rules/walk.md` |
| 没说 / 就做一条能爆的 | **默认走这条，不要问** | 系统指定的内部路线；没有指定就 `rules/pitfall.md` | 对应文件 |

客户要是反问「你问这个啥意思」，就用第二列那句话解释，别甩行话。三种方向剪出来的片子差别只在开头三秒和结尾那句话，所以**先剪一版给他看，比先问强**。

同一家店刚做过的路线不要重复。系统提示里的「这次内部成片路线」优先。

## 花字和音效（默认就要有，别只上黄底大字）

渲染器内置 22 种花字、33 个音效，靠 `dh_add_local_styled_text` 和 `dh_add_sfx` 调。**不要全片只用一种黄底大字，也不要一个音效都不配**——那是"素"和"丑"的主要来源。

按场合挑（内部决定，不问客户）：

| 场合 | 花字 style | 配的音效 |
|---|---|---|
| 开场第一句钩子 | `手写笔刷`（cream_brush_title） | `riser` |
| 卖点、数据、对比数字 | `数字放大` / `渐变金`（gradient_gold） | `count` |
| 承载一条信息（替代裸字） | `深色卡片` | `whoosh` |
| 结论、已验证、板上钉钉 | `印章` | `stamp` |
| 清单逐项 | `对勾`（文字留空）/ `勾选字幕` | `check` 或 `n1`–`n5` |
| 店名收尾 | `店招红金` / `银灰金属字` | `ding` / `outro` |
| 整句字幕条 | `白字黑边` | 不加 |

规矩：

- 一条 15–20 秒的片子，花字 **3–5 个**，样式 **2–3 种**，别全片一个模子。
- 音效 **3–5 个点**，只落在动作和重点上；不要每个镜头都配，不要铺满。
- 先 `dh_list_sfx` 拿清单再挑，**不要凭名字猜**（`cut` 是切镜头，不是剪贴板）。
- `dh_add_sfx` 一次把数组传完，`gain` 一般不用填，用默认值。
- 花字文字不超过 8 个字，别把口播原句抄上去。

## 对客户说话

只用大白话。禁止：转化、CTA、分镜、B-roll、入点、画幅、完播率、技能名、路线英文 id。

## 行业红线

- 不编价格、工期、进口、军工、永久防水、绝对不滑。
- 钩子必须踩档案里的卖点；没有卖点先问「店里主推啥」。
- 口播像邻居说话，不要广告腔。

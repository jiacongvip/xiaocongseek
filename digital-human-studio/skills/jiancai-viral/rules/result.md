# 结果先行

适用：想来店、或想先看到效果。先甩做好的样子，再倒叙。

必需素材：成品/上墙/铺好的画面。没有效果镜就改读 `walk.md` 或 `pitfall.md`。

## 成片（16–20 秒）

| 成片 | 画面 | 口播/字幕 |
| --- | --- | --- |
| 0–3s | 最好看的完成面，满屏 | 「先看做好的。」不要先介绍公司 |
| 3–9s | 倒叙 2–3 镜：半成品 → 细节 → 完成面 | 一句过程：「从选砖到铺上，关键就这一步。」 |
| 9–15s | 产品特写贴上卖点 | 卖点一句人话 |
| 15–20s | 门头或店内 | 「想来店看样，回我一声。」 |

## 钩子备选

- 先看做好的。
- 这是业主刚收的卫生间。
- 别先听我吹，先看效果。

## 剪法

- 第一镜必须是结果，禁止片头店名、禁止自我介绍。
- 倒叙不要超过 3 镜，否则会拖。
- 每镜 `dh_add_video` 带入点出点，完成面选最干净的 2–3 秒。

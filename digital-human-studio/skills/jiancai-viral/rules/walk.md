# 带进店

适用：想来店看看、想记住这家店。带人进门转一圈，像朋友带路，不像宣传片。

必需素材：门店（门头、通道、展墙、样品区）。没有门店就改读 `result.md` 或 `talk.md`。

## 成片（16–20 秒）

| 成片 | 画面 | 口播/字幕 |
| --- | --- | --- |
| 0–3s | 进门或门头，动起来 | 「带你进店看一眼。」不要店名口号开场 |
| 3–10s | 店内 3 镜：展墙 → 样品 → 一处能摸的细节 | 每镜最多半句，像带路 |
| 10–16s | 主推产品特写（有产品才上） | 卖点一句 |
| 16–20s | 门头或前台 | 顺口报位置或「来了找我，别自己瞎挑。」 |

## 钩子备选

- 带你进店看一眼。
- 别在网上猜，店里这块能摸。
- 今天店里不忙，我带你转。

## 剪法

- 禁止航拍式空镜堆砌；要有行走感和能停下来摸的点。
- 单镜 2 秒左右，进门钩子不超过 3 秒。
- 门店环境声可留一点；不要全程静音显得像库存片。
- 每镜 `dh_add_video` 带入点，选人少、货整齐的片段。

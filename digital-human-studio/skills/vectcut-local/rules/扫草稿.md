# 规则：扫草稿

适用：用户要看/选/加载已有剪映或 VectCut 草稿。

## 步骤

1. `dh_engine_status` → 离线则 `dh_engine_start`。
2. `dh_get_workspace` 看是否已有 `folder`。
3. 无文件夹：问一句，或默认  
   `/Users/jiacong/Movies/JianyingPro/User Data/Projects/com.lveditor.draft`。
4. `dh_list_drafts`（可传 `folder`）→ 列表含 name / path / mtime。
5. 用户点名或说「最新/刚才」→ `dh_load_draft`（`name` 或 `path`）。
6. 回报：当前 `draft_id`、`draft_path`，并问下一步（加片 / 保存 / 仅查看）。

## 注意

- `dh_list_drafts` 会记住文件夹，供面板与后续对话共用。
- 空目录如实说，不要假装有草稿。

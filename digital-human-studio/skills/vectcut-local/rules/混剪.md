# 规则：混剪

适用：多段本地视频拼成一条新草稿，再进剪映。

## 收集（缺一问一句）

- 视频绝对路径列表（顺序=成片顺序）
- 画幅：竖屏 1080×1920（默认）/ 横屏 1920×1080 / 方形 1080×1080
- 保存目录（默认同工作区剪映草稿父目录）
- 项目名（可选；默认用 draft_id）

## 步骤

1. `dh_engine_status` → 需要则 `dh_engine_start`。
2. `dh_create_draft`（带 width/height）。
3. `dh_add_video`：多文件优先一次 `paths: [...]`；失败再逐条 `path`。
4. `dh_save_draft`（`draft_folder` / `project_name` 按需）。
5. 告诉用户：打开 **剪映** → 对应草稿 → 预览/微调/导出。
6. 可选试 `dh_export_draft`；本机无导出接口则停止并说明走剪映。

## 配音 / 生图

本流程不调用云 TTS/生图。用户要配音或封面时：记下文案/提示词与「日后挂自有后端」；若已有本地音频/图片路径，写入回复待办，待插件补 `dh_add_audio` / `dh_add_image`。

## 注意

- 路径必须存在；不要用未下载的远程示例 URL 充数。
- 一段失败：报告哪条 path、VectCut 返回，问是否跳过继续。

# 四种段落模式与节奏

## 四种模式

| 模式 | 长什么样 | 用在哪 | 时长 | 现有工具 |
|---|---|---|---|---|
| **H 钩子** | 身后大字 + 左右两张卡 + 左上标签 | 只用于 0 到第一句话说完 | 3–5 s | 部分可做 |
| **A 口播 + 卡片** | 原片全屏，人物空着的一侧放卡片/按钮/截图，同侧加暗渐变 | 讲观点、讲感受、号召行动 | 1–5 s | ✅ 可做 |
| **B 讲解板** | 全屏深色板 + 水印 + 右上人像小窗，标题 + 内容逐条累加 | 讲步骤、列清单、展示真实截图/录屏 | 4–12 s | ❌ 需引擎 |
| **C 字在人物身后** | 顶部小白字（原话）+ 超大黄字（核心词），人物挡住大字下半截 | 情绪最强、最想让人记住的词 | 3–5 s | ❌ 需遮罩 |

## 节奏配比（以 70 秒片子为参考）

- **B 讲解板**：全片 **30–40%**。有真实素材的内容优先放进去。
- **C 字在人后**：**3–5 次**（含钩子），两次之间**至少隔 8 秒**。
- **A**：其余所有时间。**每个 A 段至少一个动起来的元素**，大多数配左上角标签。
- **不允许空白段**：任何时刻除字幕外，屏幕上至少有一个包装元素。唯一例外是两块讲解板之间的口播，可以只放一个按钮或一张卡。

## 切段原则

- 段落边界放在**句子开始前 0.1 s**（不是句尾）。下一段永远是"从一句话的开头开始"。
- 讲解板里的元素**逐条累加、不消失**，最后整板一起淡出。
- A / C 段的元素在段尾 **0.3 s 统一淡出**。
- 相邻两块讲解板首尾相接时，交叉淡化，不再做缩放。

## 内容怎么选

### 句子里有可视化名词 → 画出来

文件、按钮、App、步骤、数字、百分比、时间——这些都要变成画面：

- "评论「剪辑」" → 评论框里逐字打出"剪辑"
- "点赞关注" → 心形 / 加号 / 评论三个图标依次点亮
- "只花半小时" → 饼图计时
- "精力全耗在剪辑上" → 两条对比进度条 + 红色标签 + 印章"太亏了"

### 句子是态度和感受 → 大字 + 印章

不画具体东西，用身后大字或一句大标题，配一个印章砸下。

### 真实素材优先

- 客户给的截图、GIF、成片示例，放在旁白**提到它那一句**。
- 真实素材右下角标 `真实成片` / `真实流程`。
- 示意图右下角标 `示意`，且**不编造具体数据**。

### 号召行动句必须做互动

点赞 / 关注 / 评论「X」——要有光标点击、按钮变色、评论框打字、弹出"已分享"卡，不能只是一行字。

## 做不了的段落怎么办

B 和 C 在现有工具下做不出来（需要深色板渲染和人像遮罩）。两条路：

1. **换模式**：把 B 拆成几个 A 段（卡片放人物空侧），把 C 改成顶部大字（不做遮挡）。
2. **明确告诉客户**这段要上包装引擎，不要用花字假装——假装出来会更难看。

宁可少做两块，也不要做出"看起来很努力但很业余"的效果。

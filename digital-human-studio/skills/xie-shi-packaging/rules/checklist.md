# 交付前验收清单

**没过完这张表，不要说"出片了"。** 说了但没查，客户一打开就露馅。

## 先分清两种项（重要，别混）

| 标记 | 意思 | 你怎么做 |
|---|---|---|
| `[工具]` | 能用 `dh_*` 查 | 真去查，把数字说出来 |
| `[人看]` | **你现在没有截帧能力，查不了** | 明确说"这几项要你看一眼"，**不许**写"已检查" |

当前 49 个 `dh_*` 工具里**没有任何截帧/看图能力**。凡是要"看画面"的项，你都验不了。
遇到 `[人看]` 就老实交出去，别猜、别糊过去。**谎报比不做更糟。**

## 必查（现在就能查）

### 成片参数 `[工具]`
- [ ] 1920×1080 —— 用 `dh_export_draft` 返回的宽高，别凭印象。
- [ ] 帧率 = 原片帧率。
- [ ] 时长 ≈ 最后一句"拜拜"的时刻 + 3.5 s。
- [ ] 时长和原片一致，没有因为包装变长变短。

### 开头 0–5 秒 `[人看]`
- [ ] 2.5 秒内能看出"能领什么、怎么领"。
- [ ] 身后大字清晰，被头挡住的部分 **不超过 30%**。
- [ ] 左右卡片**不压大字、不压脸、不压字幕**。
- [ ] 大字 ≤8 个字，没有一行字挤成一片。

### 全片 `[人看]`
- [ ] **没有空白段**：任何时刻除字幕外，屏幕上至少有一个包装元素。
- [ ] 每个 A 段至少有一个元素在动。
- [ ] 每段有一个"强调时刻"（印章 / 震屏 / 闪黄 / 光圈 / 对勾 / 扫光）。
- [ ] 元素出现时间对得上词，误差 ≤0.3 s（肉眼看不出"先说后出"）。
- [ ] 卡片都在人物空着的那一侧，同侧有暗渐变。
- [ ] 所有卡片底边不压字幕。

### 字幕 `[工具] + [人看]`
- [ ] `[工具]` 字幕条数和文案表条数一致。
- [ ] `[工具]` 每条字幕的起止时间落在对应那句录音的区间内。
- [ ] `[人看]` 字幕和录音一致、没有错字。
- [ ] `[人看]` **没有方块字**（缺字形的字符）。
- [ ] `[工具]` 英文标签只写 ASCII，没有 ✓、emoji 这类符号（用文本搜索查）。

### 原片保真 `[工具]`
- [ ] 没有调色。
- [ ] 没有推拉、没有缩放人物。
- [ ] 原音轨没动过。

### 内容诚实 `[人看]`
- [ ] 示意图标了"示意"。
- [ ] 真实素材标了"真实"。
- [ ] 没有编造的播放量、粉丝数、价格、工期、绝对化效果。

## 接包装引擎后才需要查（现在没有这些能力）

- [ ] 人像遮罩已生成，字确实在人物**身后**。
- [ ] 讲解板窗口不是黑屏/空白，右上小窗里是脸。
- [ ] 音效数量 120–200 个，且和动作对得上。
- [ ] 真峰值 ≤ −1.0 dBFS，响度与原片相差 ≤1 dB。
- [ ] 结尾卡正常接在"拜拜"之后。

## 交付时怎么跟客户说

不要甩这张表。只说两件事：

1. 我查过的：画幅、时长、字幕条数对得上。
2. 你帮我扫一眼的：**画面压没压脸、有没有空场**——这个我这边截不了图。

一句话说完，别列清单吓人。

## 发现问题怎么处理

| 问题 | 处理 |
|---|---|
| 元素压脸 / 压字幕 | 挪位置或缩小，**不要**靠"应该看不出来"糊过去 |
| 时间对不上 | 重新对词的锚点，误差必须 ≤0.3 s |
| 文字撑破卡片 | 改短文案或分行，**不要**依赖自动缩小塞满 |
| 某段做不出来 | 换一种模式（A 换 C），或明确告诉客户这段要上引擎 |

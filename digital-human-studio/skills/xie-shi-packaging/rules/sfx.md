# 音效怎么配

## 现在能用了

音效库已接进系统：**33 个**，全部本地合成（无版权问题），走草稿的独立音效轨，不动画面、不动原音轨、不动垫乐。

- 查清单：`dh_list_sfx` → 返回 id / 时长 / 用途 / 默认音量
- 铺上去：`dh_add_sfx`

**先查再配，不要凭名字猜。** 同名不同用途的声音差很远（`cut` 是切镜头，不是剪切板）。

## 六类音效，按"要表达什么"挑

| 类的感觉 | id | 什么时候用 |
|---|---|---|
| 滑动 / 转场 | `whoosh` `swoosh` `suck` `send` `cut` | 卡片飞入、版面整体切走、镜头切换 |
| 点击 / 选择 | `click` `pop` `toggle` `check` `type` | 光标点击、元素弹出、开关、打勾、打字 |
| 数字 / 进度 | `count` `progress` `tick` `blip` | 数字滚动、进度走满、计时、计数器变化 |
| 强调 / 落定 | `hit` `stamp` `clap` `ding` `sparkle` | 重音落地、印章砸下、收尾拍手、达成、亮点 |
| 持续 / 可循环 | `pad_low` `loading` | 讲解板满屏时压场、等待提示 |
| 氛围 / 蓄势 | `riser` `rewind` `door` `outro` | 高潮前蓄势、倒回、进入场景、结尾收束 |
| 负面 / 异常 | `error` `glitch` `rip` | 报错、踩坑、数据异常、撕开对比 |
| 正面音阶 | `n1`–`n5` | 清单第 1–5 项，依次上行 |

## 怎么铺

```
dh_add_sfx({
  cues: [
    { at: 0.4,  id: 'riser' },
    { at: 2.6,  id: 'stamp' },
    { at: 5.1,  id: 'whoosh' },
    { at: 8.3,  id: 'count' },
    { at: 12.0, id: 'ding' }
  ]
})
```

- `at` 是时间线秒数。
- `gain` 一般**不用填**，用 manifest 里按用途定好的默认值（`stamp` 重、`blip` 轻，本来就该不一样）。
- 多个点一次传，工具会按时间顺序铺，失败的会单独列出来，成功的不用重铺。

## 对齐

- **动作落点**：音效起点 = 动画开始那一刻，不要等动画做完。
- **元素出现**：可以**提前 0.02–0.05 s**（视觉略早于声音会显得干脆，晚了会显得拖）。
- 大字逐字落下：每个字一声轻 `hit`，别每个字都 `stamp`。
- 印章：`stamp` 打在印章接触画面的那一帧。
- 清单逐条：`n1`…`n5` 按顺序，第 6 项之后换回 `check`。
- 循环音效（`pad_low` `loading`）用于持续段落，首尾已经做了无缝，可以连着铺。

## 数量：宁少不多

**60–90 秒的片子，20–40 个音效。** 不要照搬"全片 120 个"那种密度——那是整片代码渲染时的量级，我们这里是每条音效一段独立音频，铺太多草稿会变重，而且听感上会吵。

判断标准：**观众能感觉到"这一下有声音"，但说不出具体哪里响。** 如果每个动作都在响，就成了噪音。

## 红线

- **不能盖过人声。** 音量和人对不上就调 `gain` 往下，不要往上。
- **不要每个动作都配。** 一个强调时刻配一个就够。
- **不要为了"显得专业"整片铺满。** 空白处安静是对的。
- 不要从网上找音效临时塞——来源不明、风格也不统一。

## 一次配完自检

铺完自己核三件事，做不到就说清楚：

1. `dh_add_sfx` 返回的 `failed` 是不是空。
2. 音效数量在 20–40 之间（不是越多越好）。
3. 有没有哪个音效的时间点落在人声正中间的关键词上——那会听不清话。

# 开头 0–5 秒钩子（最重要的一节）

目标：**2.5 秒内让观众知道"看完我能得到什么"**，同时被大字动效抓住视线。

## 七个要素，一个都不能少

| # | 要素 | 具体做法 | 现有工具怎么落 |
|---|---|---|---|
| 1 | **起手冲击** | 0.00 s 闪白 + 上扬音 + 重拍 + 轻微震屏 | 闪白用转场/白色花字闪一下；音效见 `rules/sfx.md`（未接入时先用强转场） |
| 2 | **顶部小白字** | 第一句原话，如"兄弟们，我终于跑通了"，y≈120 | 花字，白色，字号约 62 |
| 3 | **身后超大黄字** | 核心卖点 4–8 字，如"自动剪辑"，**逐字砸下**，中心 y≈300–330 | 花字，超粗，≤8 字；逐字用多个花字错开 0.05–0.08 s |
| 4 | **左卡"证据"** | Before / After 对比：原始画面 → 箭头 → 成片截图 | 两张图片花字 + 一个箭头，或直接放一张对比图 |
| 5 | **右卡"利他"** | 写清**能领到什么** + 3 个功能点 + 按钮式标签"评论「X」领" | 一张卡片图 + 花字；2.3 s 时盖一个"免费"印章 |
| 6 | **左上角标签** | 高 74，毛玻璃底 + 左侧彩色圆点，写"$领什么 · 评论「X」领" | 花字标签 |
| 7 | **顶部暗渐变** | 压住亮背景，让黄字可读 | 一张渐变 PNG 叠在人物后面那层 |

## 布局硬规则（实测修正过，违反就是废片）

- 大字中心 **y 300–330**，字号 **≤160**。
- **左右卡片的顶边必须 ≥ y 400**，否则挡住大字两端。
- 左卡宽 ≤ 348，x 从 50 起；右卡宽 420，x 从 1450 起。
- 所有卡片**底边 ≤ y 900**，不能压字幕。
- **不压人脸**：以人脸为中心的 ±260 × ±300 范围里不放任何前景元素。
- 人物遮挡后，大字**至少 70% 笔画可见**。

## 利他内容怎么找

从文案里找这几类词：**评论 X 领 / 免费分享 / 模板 / 资料包 / 结论 / 几招**。

找不到领取物时，把本期结论做成"结论卡 + 建议收藏印章"，不要硬凑一个不存在的福利。

## 常见错误

| 现象 | 原因 | 改法 |
|---|---|---|
| 黄字在亮墙上看不清 | 背景太亮 | 先叠顶部暗渐变 |
| 大字两头被卡片挡住 | 大字太大或卡片太高 | 大字 ≤160、y 300；卡片顶边 ≥400 |
| 2.5 秒了还不知道能领什么 | 利他信息藏在后面 | 右卡 + 左上标签同时写清"领什么、怎么领" |
| 钩子拖到 8 秒 | 第一句太长 | 钩子只覆盖第一句话，3–5 s 内结束 |

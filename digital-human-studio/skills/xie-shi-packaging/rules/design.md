# 设计系统（配色 / 字号 / 安全区 / 动效）

一套片子里**只用一种主色**。多色是业余感的主要来源。

## 颜色

| 用途 | 值 | 说明 |
|---|---|---|
| 讲解板底色 | `#17181b` | 近黑，不是纯黑 |
| 深卡 / 钩子卡 | `#26272b`，白描边 10%，圆角 22 | 投影轻，不要发光 |
| 浅卡 | `#f3f2ee` | 米白，用于对比块 |
| **主强调色** | `#ffd23f`（黄） | 只用一个 |
| 辅助 | 蓝 `#5aa9ff`、绿 `#4cd38a`（成功）、红 `#ff5a5a`（负面/印章/关注） | 只做点缀 |
| 文字 | 白 / 灰 `#9ea0ab` / 黄底上的字用 `#17181b` | |

## 字号（1080p 基准）

| 元素 | 字号 |
|---|---|
| 身后超大黄字 | 160–290（**≤8 个字**） |
| 顶部小白字 | 62 |
| 讲解板标题 | 48 |
| 卡片标题 | 32–36 |
| 正文 | 24–30 |
| 标签 / chip | 20–32 |
| 英文小标签 | 12–17（只写英文，中文用正文字体） |

## 字幕

- 字号 46、白色、黑色 50% 底条、圆角 8、距底 86。
- **只显示中文**，不变色，不用花哨字体。
- 以录音为准，识别错字按文案改正（"codeax"→"Codex"、"他"→"它"）。

## 安全区

- 内容距画面边缘 **≥ 50**。
- A 段卡片**底边 ≤ 900**，不压字幕。
- **人脸周围 ±260 × ±300 内不放任何前景元素**。
- 人物一般在画面中央 x 700–1200；卡片放左侧（x 50–700）或右侧（x 1250–1870），并在同侧加一层暗渐变保证可读。

## 动效时长

| 动作 | 时长 | 曲线 |
|---|---|---|
| 入场 | 0.45–0.6 s | 缓出（po3 / expo） |
| 弹出 | 0.3–0.5 s | eback 1.3–1.8（弹性） |
| 出场 | **0.3 s** | 缓入（pi2）——**出场一定比入场快** |
| 透明度淡入 | 前 1/3 时间内到 1 | — |
| 一组元素依次出现 | 间隔 0.06–0.2 s，总时长 ≤0.8 s | — |

**不用线性运动**（进度条例外）。

## 能用的图形（已实现，直接用 style 名）

这是现有渲染器真做得出来的五个，配哪个音效都定好了：

| style | 长什么样 | 配的音效 | 什么时候用 |
|---|---|---|---|
| `印章` | 红双线框 + 字，整体倾斜 -6° | `stamp` | 结论落定、审批通过、"已验证" |
| `深色卡片` | 深色圆角底 + 左侧黄条 + 白字 | `whoosh` | 承载一条信息，替代裸字 |
| `对勾` | 绿圆 + 白勾（**纯图形，文字留空**） | `check` | 清单逐项完成 |
| `数字放大` | 超大数字 + 黄内衬 + 深描边 | `count` | 讲数据、讲对比 |
| `银灰金属字` | 上亮下暗的金属渐变 | `sparkle` | 强调一句（比白字更有分量） |

调用就是 `dh_add_local_styled_text({ text: '已验证', style: '印章' })`。位置和时长有默认，不用手填。

**五个图形各用一次就够，别一条片子里全是印章。**

## 做不到的（别承诺，也别拿花字冒充）

| 想要的效果 | 状态 |
|---|---|
| 横扫光（高光条扫过文字） | ❌ 静态 PNG 做不出，要逐帧渲染 |
| 光圈 / 扩散波纹 | ❌ 同上 |
| 震屏 / 闪白 | ❌ 需要整帧位移或调色 |
| 毛玻璃 / 七层柔和阴影 | ❌ PIL 做不出这种质感 |
| 字在人物身后 | ❌ 需要人像遮罩 |

遇到这些：**换一个能做的方式表达**（比如用印章代替光圈），或者明确告诉客户这段要上引擎。

## 每段必须有"强调时刻"

每段至少选一个：**印章、对勾、数字放大、深色卡片**。

如果一个段落平平静静过去，说明这段没做完。

## 内容与画面的对应

| 句子里出现 | 画什么 |
|---|---|
| 文件 / 按钮 / App / 步骤 / 数字 / 百分比 / 时间 | **画出来**（评论框打字、三个图标依次点亮、饼图计时） |
| 态度、感受、结论 | 身后大字 + 一个印章 |
| 真实截图 / 录屏 / 成片 | 放在旁白提到它的那一句，**右下角标"真实"** |
| 示意图 | **右下角标"示意"，且不写具体数据** |

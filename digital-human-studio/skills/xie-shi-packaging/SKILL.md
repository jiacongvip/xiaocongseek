# 写实包装口播（内部技能）

给**模型**用，不给客户点。目标：把一条**已剪好的口播片**叠一层"写实产品界面"的动效包装。

客户不会说"写实包装"这个词。他们说"做得高级一点""太素了""讲清楚一点"时，就是想要这个。

本技能只管**包装怎么排**，不管剪辑。下游走 `xiaocongcut-local` 的 `dh_*`。

## 先判断能不能用

**能包装**：已有初剪成片、有完整口播、已带 BGM、内容是讲解型（观点 / 步骤 / 对比 / 结论）、16:9 横屏为主。

**不要包装**：还在改分镜和节奏；纯产品展示、探店实拍（没有口播可对齐）；竖屏短视频（这套是横屏版式）；客户要自己反复改每一个字（改字成本高）。

## 全片结构（按这个配比排）

| 段 | 作用 | 占比 | 现有工具能否做 |
|---|---|---|---|
| **H 钩子** | 0–5 s，身后大字 + 左右两张卡 | 每片 1 次 | 大字 + 深色卡片都可以；但字在人物身后做不到 |
| **A 口播 + 卡片** | 讲观点 / 号召，人物空着的一侧放卡 | 其余时间 | ✅ 可以（深色卡片 + 黄条） |
| **B 讲解板** | 深色板 + 右上人像小窗 + 内容逐条累加 | 全片 30–40% | ❌ 需要包装引擎 |
| **C 字在人物身后** | 超大黄字，人物挡住下半截 | 3–5 次，间隔 ≥ 8 s | ❌ 需要人像遮罩 |
| **音效层** | 强调时刻配音、持续段落压场 | 贯穿全片 | ✅ 33 个（含可循环），走独立音效轨 |

**做不到的段落不要硬做**。直接跟客户说"这一段要上包装引擎"，不要用普通花字冒充讲解板——那会显得业余。

## 每次必做

1. `dh_get_brief` + `dh_list_materials`，只用 ready 条目的 path / 时长 / useFor，不重看原片。
2. 把口播切成句子，记下每句开始时间（以本次字幕/时间线为准）。
3. 按配比排段：钩子 → A → B → C → 结尾。段落边界放在**句子开始前 0.1 s**。
4. 每个 A 段至少有一个动起来的元素；**不允许空白段**（除字幕外屏幕上要有东西）。
5. 元素出现时间 = 对应词**提前 0.1–0.3 s**（视觉略早于声音）。大字逐字出现从词前 0.4–0.5 s 开始。
6. 身后大字 **≤ 8 个字**，顶部小白字是原话，大黄字是核心卖点。
7. 句子里有可视化名词（文件、按钮、步骤、数字、百分比、时间）就画出来；态度和感受用大字 + 印章。
8. 配音效：`dh_list_sfx` 查表 → 按强调时刻挑 **20~40 个**（不是每个动作都配）→ `dh_add_sfx` 一次铺完。持续段落用可循环的 `pad_low` / `loading`。详情见 `rules/sfx.md`。
9. 交付前按 `rules/checklist.md` 过一遍。**`[工具]` 项真去查、把数字说出来；`[人看]` 项明确交给客户看**——你没有截帧能力，不许写"已检查"。

## 红线（违反任何一条都返工）

- 不剪辑、不调色、不推拉、不缩放人物。
- 原音轨一个字节不动。
- 不编造数据（播放量、粉丝数、价格、工期、进口、绝对化效果）。
- 示意内容标"示意"，真实素材标"真实"，两者不能混。
- 对客户只用大白话：不说分镜、B-roll、CTA、入点出点、完播率、技能名。

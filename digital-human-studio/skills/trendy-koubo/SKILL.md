# 网感口播 · 本机直出（Xiaocongseek）

## 视觉规范（默认：`trendy_red` 高级红）
1. **前 5 秒双行反色大标题**：上行粗黑体白字 + `#A81C23` 厚红边，下行思源粗宋 `#A81C23` 红字 + 厚白边；每行严格 **≤8 字**，无标点、直击冲突或结果。
2. **中英双语 + 错落分层字幕**：
   - 思源粗宋白字黑边投影；
   - **1–7 字**：底部居中单行 + 正下方小号英文字幕；
   - **8–12 字**：自动拆成**左上 + 右下错落双行** + 对应小号英文字幕。
3. **关键词高亮放大弹动**：每条字幕挑选 **1 个**语义最强的实词 / 数字 / 痛点词（如「七八套」「0成本」「直接省一半」），以放大字号 + 主题主色 + 厚反色描边弹出；虚词引导句传 `""` 不高亮。
4. **节奏与声音**：默认去气口（或按停顿切镜）、全片选 1 处最金句加 `1.18x` 缩放强调、段间 2–3 处干净转场、开头/结尾克制提示音 + 低音量氛围 BGM 自动压人声。
5. **可选配色皮肤**：
   - `trendy_red`：网感口播 · 高级红（默认，思源粗宋 + 暗红白边，商业/知识/门店口播通杀）
   - `trendy_gold`：黑金杂志（思源粗宋暖白 + 香槟金，高端访谈/品牌故事）
   - `trendy_cyan`：极简白青（兰亭黑 + 冰青，科技/效率/教程）

## 3 步极简执行流程（单次语义规划，严禁来回多轮折腾）

### 第 1 步：读口播原声 + 公司档案（如适用）
- 若在具体公司空间下，可先读 `dh_get_brief`（了解行业定位、禁忌、口吻与视觉偏好）。
- 调用 `dh_transcribe({ path: 视频绝对路径, words: true })` 获取带精确时间戳的口播分句。

### 第 2 步：单次语义规划（一次性在思考里产出规划，不写临时文件）
严格按以下规则把转写内容规划成结构化参数：
- `title`：`{ "top_title": "≤8字", "bottom_title": "≤8字" }`（概括全片最大冲突/利益点，无标点空格）。
- `subtitle_items`：每条 `{ "text": "≤12字", "en": "≤8词简短英文", "keyword": "text里的精确子串或空串", "start": 秒, "end": 秒 }`：
  - 忠实原话，严禁编造或篡改原意；超过 12 字的句子拆成相邻两条并按词级时间切分 `start/end`；
  - 1–7 字走居中单行，8–12 字自动走左上+右下错落双行。
- `zoom`：全片只选 **1 条**最金句的下标 `{ "trigger_sub_index": idx, "scale": 1.18 }`。
- `tone_presets`：`emphasis`（开头钩子句）和 `result`（结尾结论句）各最多 1 次。
- `transitions`（多段素材时）：段间从 `向右` / `向左` / `竖向模糊` 选 2–3 处，首段不加。

### 第 3 步：一键本机渲染直出 mp4
调用 `dh_trendy_koubo`：
```json
{
  "video_path": "/本地绝对路径/oral.mp4",
  "theme": "trendy_red",
  "name": "成片标题",
  "title": { "top_title": "别买七八套软件", "bottom_title": "一套后台全装下" },
  "subtitle_items": [
    { "text": "我见过不少老板", "en": "Many shop owners I met", "keyword": "老板", "start": 0.0, "end": 1.4 },
    { "text": "店里七八套软件各玩各的", "en": "use seven disconnected tools", "keyword": "七八套软件", "start": 1.4, "end": 3.2 }
  ],
  "zoom": { "trigger_sub_index": 1, "scale": 1.18 },
  "tone_presets": [
    { "tone_type": "emphasis", "trigger_sub_index": 0 },
    { "tone_type": "result", "trigger_sub_index": 1 }
  ],
  "bgm": "auto",
  "voice_fx": "clean"
}
```
- 输出模式控制（根据用户要求灵活传参）：
  - **成片 + 剪映草稿（默认）**：`render_mp4: true, export_jianying_draft: true` — 同时直出 `.mp4`（入「成片库」）、导出剪映 Pro 多轨草稿、保存「剪辑台」工程；
  - **仅直出 mp4**：`render_mp4: true, export_jianying_draft: false` — 只本机渲染成片，不写剪映草稿；
  - **仅出剪映草稿（秒出）**：`render_mp4: false, export_jianying_draft: true` — 跳过 ffmpeg 编码，1–2 秒直接导出完整多轨剪映草稿（视频主轨、双行反色标题轨、中英双语错落与关键词高亮字幕轨、提示音轨、BGM 轨）。
- 完成后把实际产出的 **成片路径和/或剪映草稿名称与目录** 明确告知用户。

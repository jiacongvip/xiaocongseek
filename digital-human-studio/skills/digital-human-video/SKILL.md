# 数字人口播视频

四步：**选形象音色 → 写口播 → 提交 → 轮询到成片**。能力全在 `dh_avatar_*` 工具里，走 XiaocongAPI 的 `xdh-*` 模型异步跑。

## 第一步 · 看资源库，别急着克隆

形象和音色存在 `~/.dsh/digital-human-assets/library.json`，`avatars` / `voices` 两个数组，每项有 `id`、`name`、`modelCode`。

- **有现成的就用现成的。** 库里没有用户要的形象，再谈克隆。
- 用户没提"用我的声音/我的形象"，就别调 `dh_avatar_clone_*` —— 克隆要等几分钟，也可能花钱。
- 确需克隆：先说清"要传一段素材、大概等几分钟"，等他同意再调；`sample_url` 必须是公网可访问地址，本地文件先用上传工具转成 URL。

## 第二步 · 写口播

- 15 秒约 45–60 字，20 秒约 60–80 字。别写超了让语速去迁就。
- 一句一个信息点，能直接念出口。书面语、"综上所述"这类一律删。
- 开头一句要能钩住人，结尾一句要有落点（让人来问价 / 来店里 / 记住店）。
- 数字和门店名要念得顺，别写"¥1,299 起"这种要念半天的写法。

## 第三步 · 提交

```
dh_avatar_create_video({
  text: '口播稿',
  model_code: 'VPro',
  selected_avatar_model_id: '<资源库里的形象 id>',
  selected_voice_id: '<资源库里的音色 id>',
  title: '这批砖别买错'
})
```

- `model_code` 是上游档位：视频 `VPro / Pro / Max / XPro`，语音 `SPro / Pro / Max / NWMax`。不填就沿用资源库那个形象自带的 `modelCode`。
- 只配声音不发视频：`dh_avatar_create_audio`（参数更少，只有 text / voice / language）。
- 要画面素材（形象图、封面）：`dh_avatar_create_image`，走 `/v1/images/generations`。

## 第四步 · 轮询到成片（最容易偷懒的一步）

提交返回里有任务 id（字段可能是 `task_id`，也可能是 `id`），拿它查：

```
dh_avatar_task({ task_id: '<id>' })
```

状态会依次走：`NOT_START` → `SUBMITTED` → `QUEUED` → `IN_PROGRESS` → `SUCCESS` / `FAILURE`。

- 第一次等 10 秒再查，之后每 15–20 秒一次，连续查最多 5 分钟。
- `SUCCESS`：取出结果视频地址，交付给用户。
- `FAILURE`：读失败原因，按下表处理，别原样重试。
- 超过 5 分钟还是 `IN_PROGRESS`：告诉用户"还在跑，我过会儿再看"，把任务 id 记着继续跟，**不要重提一条**。

| 失败原因类型 | 怎么办 |
|---|---|
| 文案/内容审核不过 | 改口播重提，不要连续试同一句 |
| 素材不合规（形象/音色样本） | 换素材，或改用库里现成的形象 |
| 服务超时、上游异常 | 同档位重试一次 |
| 连续两次失败 | 降一档（Max → Pro → VPro）再试，并告诉用户"降档了，画面细节会差一点" |

## 硬规矩

1. **没到 `SUCCESS` 不许说"做好了"。** "已提交"就回"提交了，正在生成"，这是两件事。
2. **不许把任务 id 甩给用户**让他自己去后台查。你自己轮询。
3. **一次只交付一条。** 用户要改文案，就重提一条新的，别在旧任务上打补丁。
4. **不擅自换形象。** 用户指定了就用指定的，哪怕库里有更像的。
5. **不承诺时长和画质。** 只说"大概 X 秒的口播"，实际时长按生成结果。

## 对客户怎么说

用大白话。别说 `xdh-avatar-video`、`model_code`、`VPro`、`task_id`、轮询、上游。

交付时三句话够了：

> 用你库里那个形象配了「我的声音」，18 秒，讲的是"这批砖别买错"。
> 视频在下面，直接下。要换成店门口那个形象、或者把结尾改成"来店里看"，跟我说一声。

要换档位：说"画质想再好点，我升一档重做，大概多等两分钟"，不要报档位英文名。

## 反模式

- ❌ 提交完立刻回"视频做好了"
- ❌ 没问就调克隆，让用户干等
- ❌ 口播稿写成公众号推文，念出来像念文件
- ❌ 任务失败直接重提，不看原因，也不告诉用户
- ❌ 把 `task_id`、`IN_PROGRESS`、`xdh-` 这些词丢给用户
